This module was written to extend the functionality of stock pickings and allow
you to manage sort of the stock pickings moves..

You can set the default sort order for the current company or you can set sort
order for a particular stock pickings.

**Table of contents**

.. contents::
   :local:

Configuration
=============

* Two sort criteria items can be selected from a list of all fields which are available
  on stock moves.

Usage
=====

#. Go to **Inventory > Settings > Default Sort Criteria** and select up to two criterias.
#. You must select sort direction too.
#. Create a new stock picking and add several moves.
#. On saving stock picking you can see how the moves are ordered
   with your selected sort order.
